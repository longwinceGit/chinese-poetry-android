## 一、易用性（Usability）

### ✅ 已有优势
| 功能 | 说明 |
|------|------|
| 底部导航 4 Tab | 首页/学习/游戏/我的，结构清晰 |
| 朝代筛选 Chip | 横向滚动 ChipGroup，支持全部分类 |
| 搜索 debounce 500ms | 标题/作者/诗句全文搜索，结果上限 500 |
| 诗词详情页 | 拼音切换 + 释义显示 + 收藏/朗读/分享/已学四按钮 |
| 填空撤销 | 点击已填写空位可撤销单个答案 |
| 填空自动提交 | 填满所有空白自动判定，无需手动点提交 |
| 加载更多 | GridLayout + 分页 30 条，按钮 + 进度条状态管理 |

### ❌ 改进机会（P0-P3）

| 优先级 | 问题 | 影响 | 建议方案 |
|--------|------|------|---------|
| **P0** | 无新手引导 | 首次用户不知道游戏怎么玩 | 首次启动 → 3 页滑动引导（介绍 3 种游戏 + 打卡） |
| **P1** | 游戏无返回按钮 | 用户靠系统 back 键退出，体验差 | 每个游戏顶部加 Toolbar + 返回箭头 |
| **P1** | 对诗游戏不展示正确答案 | 答错后不知道为什么错 | feedback 区域显示"正确答案：xxx" |
| **P1** | 详情页旋转丢状态 | fragment_detail.xml 在 NestedScrollView 内，Fragment 重建后滚动位置归零 | `onSaveInstanceState` 保存 scrollY + pinyinVisible |
| **P2** | 搜索无历史 | 重复搜索同一诗人需重新输入 | Room 存储最近 10 条搜索记录 → 搜索框下展示 |
| **P2** | 诗词列表无收藏标记 | 看不出哪些已收藏 | PoemAdapter 卡片加 ⭐ 角标 |
| **P2** | 每日任务只读 | 用户看到"已学1首诗"但无法直接跳转 | 任务卡片点击 → 跳转到对应功能 |
| **P3** | 无长按操作 | 诗词卡片功能单一 | 长按 → 弹出菜单（收藏/分享/朗读） |

## 二、流畅性（Smoothness）

### ✅ 已有优势
| 功能 | 说明 |
|------|------|
| 卡片点击动画 | PoemAdapter 按压缩放 + OvershootInterpolator 回弹 |
| 消消乐动画 | 消除缩放淡出 (300ms) + 失败抖动 (250ms) |
| 对诗反馈 | 正确/错误颜色反馈 + 1.5s 自动下一题 |
| 拼音开关 | 即时切换无延迟 |

### ❌ 改进机会

| 优先级 | 问题 | 根因 | 建议方案 |
|--------|------|------|---------|
| **P0** | 启动时全量加载 91K 首诗 | `PoemLoader.loadAll()` 一次性解析 54MB JSON → 加载 3-5 秒 | 延迟加载：首屏只解析 500 首著名诗词，后台线程逐步解析其余 |
| **P1** | 搜索 O(n) 线性扫描 | `PoemRepository.search()` 遍历 91K 对象 | 为 title/author/firstLine 建立 `HashMap<String, Set<Integer>>` 倒排索引 |
| **P1** | 无骨架屏 | 加载期间只显示"正在加载诗词..."文本 | 添加 Shimmer 骨架屏占位（Card 形状灰色闪烁） |
| **P1** | setCategory 重新构建全量 List | 每次切换类别都从 allPoems 遍历过滤 → GC 压力 | 预建 `Map<String, List<Poem>>` 缓存 |
| **P2** | GridLayout 无 prefetch | 3 列网格滑动时有轻微掉帧 | `recyclerView.setItemViewCacheSize(20)` + `setHasFixedSize(true)` |
| **P2** | 分享卡片在主线程生成 | `generateShareCard()` 在 background thread 但 Paint 操作仍耗时 | 预生成常见尺寸 Bitmap 缓存 |
| **P3** | 无 ProGuard/R8 优化 | proguard-rules.pro 空文件 | 启用 R8 minification + shrinkResources |

## 三、趣味性（Fun）

### ✅ 已有优势
| 功能 | 说明 |
|------|------|
| 3 种游戏 | 对诗接龙（10题） + 诗词消消乐（6对12卡） + 填空挑战 |
| 积分系统 | 对诗连击加分 + 消消乐效率计分 + 填空正确率计分 |
| 9 级等级 | 诗词小学徒 → 千古诗圣，每级经验递增 |
| 12 成就 | first_poem / streak_7 / poem_100 / quiz_perfect_5 等 |
| 连续学习 | streak 追踪 + 7 天倍数弹窗祝贺 |
| 每日推荐 | 基于日期 hash 固定推荐（同一天同一首） |
| 打卡日历 | 本周 7 天可视化，今日/已签/断签/未来 四种状态 |
| 纸屑动画 | ConfettiView 60 粒子彩色纸屑 + emoji |
| 9 套主题 | 墨韵/春意/夏荷/秋月/冬雪/竹韵/莲心/金榜/传奇（按等级解锁） |

### ❌ 改进机会

| 优先级 | 问题 | 影响 | 建议方案 |
|--------|------|------|---------|
| **P0** | 主题系统未接入 UI | 9 套主题定义完整但 `ThemeManager` 从未被 Fragment 调用 | ProfileFragment 加"切换主题"按钮，app:theme 根据当前主题切换 |
| **P0** | 成就解锁无庆祝 | 成就静默解锁，用户根本不知道 | `AchievementEngine.checkAndUnlock` → 触发 `ConfettiView.celebrate()` + 底部 Snackbar |
| **P1** | 游戏无音效 | 配对成功/失败/完成无声音反馈 | 集成 `SoundPool` 播放短音效（正确.mp3/错误.mp3/完成.mp3） |
| **P1** | 对诗无难度递进 | 10 题随机，前期简单后期难没有体现 | 前 3 题选短诗（4-5 言），后 7 题混合 |
| **P1** | 消消乐固定 6 对 | 每次 12 张卡片，无难度变化 | 增加 4 对（简单）/ 8 对（困难）可选 |
| **P2** | 积分无用途 | 积分只升级，升级只解锁主题 | 增加积分商城概念（用积分换 emoji/主题/音效包） |
| **P2** | 无排行榜 | 无社交动力 | 本地"本周学习最多"排行榜（基于 DailyStats） |
| **P2** | 每日一句太简单 | 只是显示一首诗，无交互 | 加"每日挑战"：回答关于今日诗词的 1 道选择题 |
| **P3** | 填空候选词固定 40 个 | 重复率高，干扰项不够随机 | 从当前诗词池动态抽取同部首/同语义的字 |

## 五、可用性（Availability / Accessibility）

### ✅ 已有优势
| 功能 | 说明 |
|------|------|
| 完全离线 | 所有数据在 assets，零网络依赖 |
| Room 持久化 | 用户数据（收藏/已学/积分/成就/打卡） |
| TTS 语音 | 中文朗读 + 语速 0.85 + 错误降级提示 |
| 文件分享 | FileProvider + Intent.ACTION_SEND |
| 数据量充足 | 91,196 首诗词覆盖先秦到清代 |
| 释义 88 首 | 100% 匹配，自动显示/隐藏 |

### ❌ 改进机会

| 优先级 | 问题 | 影响 | 建议方案 |
|--------|------|------|---------|
| **P0** | 零无障碍适配 | 视障用户完全无法使用 | 所有 TextView/ImageView 加 `android:contentDescription` |
| **P1** | 无字体缩放适配 | 系统字体调大后布局错乱 | 所有 sp 单位 + `ConstraintLayout` 约束链确保不溢出 |
| **P1** | 诗意朗读无进度条 | TTS 播放时用户不知道进度 | 加 `UtteranceProgressListener` + 底部播放进度条 |
| **P1** | 无数据备份 | 换手机丢失收藏和学习记录 | Room 数据库导出/导入功能（或云同步预留接口） |
| **P2** | 填空游戏数据缺失会崩溃 | QuizGenerator 依赖 poem.lines.length>0，无 fallback | 加 null/empty 保护 + Toast "暂无可用诗词" |
| **P2** | TTS 不可用时体验差 | 只有 Toast + 按钮无反应 | 朗读按钮在 TTS 不可用时灰显 + tooltip"需要安装中文语音包" |
| **P2** | 无 crash 上报 | 线上问题无法感知 | 集成 Firebase Crashlytics（仅需 3 行代码） |
| **P3** | 释义仅 88 首 | 占总量 0.1% | 后台用 AI 补全更多释义（分批次加入） |

| **P0** | 无推送通知 | 用户装了可能忘记打开 | 每日 8:00 推送今日诗词（WorkManager + NotificationCompat） |
| **P1** | 无个性化 | 所有用户看到完全一样的界面 | 首次启动选昵称 + 头像（emoji 选择器） |

| **P2** | 评论/笔记缺失 | 用户无法记录读诗感悟 | Room 表 poem_notes(id, poemId, text, timestamp) |
| **P3** | 无节日特别内容 | 端午节/中秋节无特别诗词推荐 | 日期检测 → 推荐相关节日诗词 |
