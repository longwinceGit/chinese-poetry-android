## 1. 设计原则（Design Principles）

| # | 原则 | 落地策略 |
|---|------|----------|
| ① | **古韵现代表达** | 楷体 + 宣纸 + 印章，结合 Material 3 组件化与圆角 |
| ② | **内容优先** | 详情页正文占比 ≥ 60%，工具栏隐于角落 |
| ③ | **即时反馈** | 任何点击 ≤ 100ms 有视觉响应（涟漪/状态变化） |
| ④ | **零负担** | 字号 100/125/150% 三档；减少动画开关；不打断式通知 |
| ⑤ | **仪式感** | 今日诗笺每日一换、成就用印章动画、连击用🔥粒子 |

### 2.4 圆角 · 阴影 · 动效

**圆角**
- `radius/xs` 4dp · 输入框、chip
- `radius/sm` 8dp · 朝代宫格、小卡
- `radius/md` 12dp · 卡片、底部弹层
- `radius/lg` 16dp · 大卡、模态
- `radius/xl` 20dp · 手机外壳示意
- `radius/full` 50% · 头像、圆形按钮

**阴影（宣纸纸感）**
- `shadow/sm` `0 1px 2px rgba(61,40,23,0.08)`
- `shadow/md` `0 2px 6px rgba(61,40,23,0.10)`
- `shadow/lg` `0 6px 16px rgba(61,40,23,0.14)` · 弹层

**动效曲线（古韵感）**
- `easeInOutQuint` · 落墨 / 卷轴 / 页面切换（400-450ms）
- `easeOutBack` · 按钮按下 / 卡片出现（250-300ms）
- `easeOutCirc` · 列表滑动 / 拼音切换（200-300ms）
- `linear` · 进度条（与时长绑定）

**Durations**
- 快速反馈 150-200ms
- 卡片 250-300ms
- 页面切换 350-450ms
- 庆祝时刻 600-800ms（印章落下 700ms）

## 4. 核心界面规范

### 4.1 首页（Home · "一眼定锚"）

**5 大区块（已落地为线框图）**

| 区块 | 高度 | 关键元素 |
|------|------|----------|
| ① 时辰问候 | 48dp | 时辰化文案（晨/午/暮/夜）+ 农历日期 |
| ② 全局搜索 | 48dp | 圆角 24dp · 🔍 + 占位 "搜标题/作者/全文" |
| ③ 今日诗笺 | 120dp | 红色左条 4dp · 楷体标题 + 4 句预览 + "轻触展开→" |
| ④ 朝代宫格 | 116dp | 4×2 宫格 · 颜色边框 + emoji + 朝代名 |
| ⑤ 学习进度 | 64dp | 进度条 + "距 XX 差 N 句" |

**底部导航**：4 Tab（学/看/玩/账）· 当前态用朱红 + 700 字重

### 4.2 详情页（Detail · "沉浸阅读"）

**8 大交互细节（已落地为线框图）**

1. 阅读沉浸感：楷体 16-18sp · 行距 1.8 · 居中
2. 拼音切换：顶部 Chip · 标点位置留空
3. 朗读（TTS）：逐句高亮 + 滚动 · 0.8x-1.5x · 男女声
4. 收藏 · 心飞粒子：点击 ⭐ → 红色「❤」粒子四散
5. 分享 · 古风卡片：750px 宣纸 + 印章
6. **长按唤菜单（核心）**：复制 / 收藏 / 翻译 / 生字
7. 上下滑切诗：Edge gesture 切下一首
8. 双指捏合切换字号：100/125/150%

**布局比例**
- Top bar：48dp（返回/收藏/分享）
- 朝代徽标区：32dp（朝代色 chip + 称号）
- 标题区：60dp（楷体 20sp）
- 工具栏：48dp（Chip × 4）
- 正文区：**剩余空间**（占比 ≥ 50%）
- 释义区：折叠时 0dp，展开时 80-120dp

### 4.3 游学中心（Game · "动力引擎"）

**4 大游戏入口（已落地为线框图）**

| 游戏 | 配色 | 积分 | 机制 |
|------|------|------|------|
| 配字消消乐 | `#C0392B` 朱红 | +5/对 | 3×4 网格 · 限时 60s |
| 拼句 | `#B8860B` 金 | +8/句 | 拖拽乱序 · 三档 |
| 对句 | `#1A8754` 竹青 | +10/对 | 上联选下联 · 含典故 |
| 选字填空 | `#7B1FA2` 紫 | +6/题 | 5 题一轮 · 上下句互选 |

**成就解锁动画**（已落地）
- 时长 700ms
- 印章从上方 200dp 落下 · easeInOutQuint
- 落地后 -8° 旋转 + 轻微回弹
- 同时顶部 toast "🏆 解锁「诗仙」"

**答题页 5 段反馈**
- 答对：`#1A8754` 绿框 + 文案"妙哉！句意浑然"
- 答错：`#D32F2F` 红框 + 提示"再思片刻" + 显示正解
- 中性：保持 `#A0522D` 茶褐
- 连击：连续正确时右上角 🔥+1
- 跳过：长按选项 → 显示解释

### 4.4 我的（Profile · "账本 + 控制台"）

**布局**（已落地）
- 顶部：圆形头像（44dp 朱红） + 诗友昵称 + 称号 + 连击
- 数据条：3 列（已学 / 积分 / 连续），数字 13sp
- 成就墙：6×N 宫格，未解锁用灰底 + 🔒
- 设置列表：圆角 6dp 行高 28dp，右侧 ›
