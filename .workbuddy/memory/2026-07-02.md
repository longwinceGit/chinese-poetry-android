## 修复消消乐配对后闪退 Bug
- **现象**: 配对成功后 app 自动退出
- **根因**: `v2.animate().withEndAction(() -> viewModel.tryMatch(...))` 在 ViewPropertyAnimator 动画生命周期内同步调用 `tryMatch()` → `matchCards.setValue()` → LiveData 同步触发 observer → `adapter.setCards()` → `notifyDataSetChanged()`
- **崩溃原因**: `notifyDataSetChanged()` 在 RecyclerView 布局过程中被调用，抛出 `IllegalStateException: Cannot call this method while RecyclerView is computing a layout`
- **修复**: `withEndAction` 回调中加一层 `handler.post(() -> { viewModel.tryMatch(...); lockInput = false; })`，将数据更新推迟到下一帧，脱离动画生命周期
- 同时修复 else 分支（视图不可用情况），同样用 handler.post
- 编译验证: BUILD SUCCESSFUL ✅
